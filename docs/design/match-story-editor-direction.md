# 賽事故事編輯區

Mode: Operate。已核可Task5在現有賽事工作台的局部延伸，不重新設計影片、不做新概念選擇。

## Direction contract

THESIS: 讓編輯能從本場來源讀到看點、改稿並簽核特定版本；不把指標盤點當故事。

OWN-WORLD: 繼承工作台暗色中性底、金色操作焦點、既有字型及shadcn控制項，不改DESIGN.md。創作者在桌機連續核稿，手機用來回讀；深色延續已在使用的工作環境。

STORY: 匯入人工研究包，查看來源與限制，選主線，逐段編輯並保存，確認後顯示待製作。不允許看點待查證時確認。

FIRST VIEWPORT: 保留賽事選擇欄，故事區接在其後並跨工作台兩欄；左側來源及事實，右側候選與旁白。手機按閱讀順序排單欄。保存與確認放在稿件末端，版本狀態在編輯區頂端可找。

FORM: 現有表單工作台的局部擴充，無seed round、无comp。人工研究包入口不裝飾成自動研究成果。

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

驗收：兩輪1280×800及375×812；匯入、選題、改稿、保存、確認、失敗重試、換場及來源安全。無新圖片、服務費、發文。
